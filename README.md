# 🌱 GoodDeeds

GoodDeeds is a mobile application that encourages users to do good, record their good deeds, and build a positive daily habit.

The app turns good actions into a simple progression system where users can track their journey, complete levels, and unlock rewards for their achievements.

## ✨ Features

- 🔐 User Registration & Login
- 🌱 Add and record good deeds
- 🏠 View saved good deeds
- 👤 Personal user profile
- 📊 Track good-deed progress
- 🎮 Level-based progression
- 🎁 Rewards for completing levels
- 🔒 Secure password handling
- ☁️ Cloud-based backend
- 📱 Android application

## 🎮 Level System

GoodDeeds encourages users to keep doing good through a progressive level system.

| Level | Requirement | Reward |
|------|-------------|--------|
| 🌱 Level 1 | 100 Good Deeds | 🎁 Reward |
| 🌿 Level 2 | 1,000 Good Deeds | 🎁 Reward |
| 🌳 Level 3 | 10,000 Good Deeds | 🎁 Reward |

More levels and rewards can be introduced in future versions.
